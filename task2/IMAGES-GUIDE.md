# Как заменить изображения

Все изображения на сайте сейчас — это сгенерированные SVG-заглушки: тёмный
фон, золотая рамка-уголок, векторная эмблема по теме и подпись вида
`--img-catalog-3` с рекомендуемым размером в пикселях. Подпись прямо на
картинке помогает понять, какой файл за что отвечает, ничего дополнительно
искать не нужно.

Менять изображения можно двумя способами.

## Способ 1. Проще всего — сохранить то же имя файла

1. Откройте папку `img/`.
2. Подготовьте своё изображение (фото модели, рендер, скан и т.д.).
3. Назовите его **точно так же**, как заменяемый файл, но с расширением
   вашего формата, например `catalog-3.jpg` вместо `catalog-3.svg`.
4. В `style.css` найдите строку с этим классом (например `.media--catalog-3`)
   и поменяйте только расширение в пути:

   ```css
   /* было */
   .media--catalog-3{ background-image: url("img/catalog-3.svg"); }

   /* стало */
   .media--catalog-3{ background-image: url("img/catalog-3.jpg"); }
   ```

5. Старый `.svg`-файл можно удалить из папки `img/` — он больше не используется.

Правило простое: **у каждой карточки/фото есть ровно одна строка в
`style.css`, которая управляет её картинкой** — блок «Карта: класс →
файл» ниже показывает, где искать нужную строку.

## Способ 2. Своя структура имён

Если хотите использовать свои названия файлов (например, реальные имена
фотографий), просто поменяйте путь в соответствующей строке `style.css`
на любой другой, ведущий в папку `img/` (или в подпапку внутри неё):

```css
.media--catalog-3{ background-image: url("img/moi-foto/legion-01.jpg"); }
```

Работает любой веб-формат: `.jpg`, `.png`, `.webp`. Для фотографий покраски
лучше подходит `.jpg`/`.webp` (меньше вес), для логотипа/фавикона — `.svg`
или `.png` с прозрачным фоном.

## Важно про пропорции

Каждый `.media` — это `background-size: cover`, то есть изображение
обрежется по краям, чтобы заполнить блок, без искажения пропорций. Чтобы
не терялась важная часть кадра (например, лицо миниатюры), старайтесь
подбирать фото с похожим соотношением сторон, указанным в таблице ниже, и
держите главный объект ближе к центру кадра.

## Если нужно добавить/убрать карточку

Количество карточек каталога, услуг и галереи задано прямо в `index.html`
(каждая карточка — один блок `<article class="card">…</article>` или
`<figure class="shot">…</figure>`). Чтобы добавить ещё одну:

1. Скопируйте один существующий блок целиком (например, весь `<article
   class="card …">…</article>`).
2. Вставьте копию рядом с остальными такими же блоками.
3. Замените текст и класс `.media--…` на новый — и добавьте для него новую
   строку в `style.css` по образцу уже существующих (см. таблицу выше).

CSS Grid сам пересчитает сетку и добавит новую ячейку — ничего в
расположении менять не нужно.
